# WLKY — brag plan

**What:** WLKY is a walkie-talkie app: many channels, many people per channel, one big PTT key. **For:** friends, families, groups on the move. **Different:** audio, chat and names are encrypted on the phone (server hears nothing), and it works with no internet.
**Angle:** the radio *is* the video. The real WLKY radio UI (markup + CSS from `public/index.html`) does its job in front of a stranger: push, talk, queue, switch channel, stay private, work offline.
**Tone:** default (punchy, playful, clean). 1920x1080, 30fps, 20s, 120 BPM (beat = 0.5s), A minor. Every cut on a beat.
**Identity:** shell orange #f6a21a, ink #151515, display white, DSEG14 / DSEG7 / Nunito / Share Tech Mono (all from the app).

| Time | Beats | Scene | On screen |

| 17.5-20 | 35-39 | Punchline | Orange wipe, icon, WLKY, "Free on Android", wlky.app |
